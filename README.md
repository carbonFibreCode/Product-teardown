# Product-teardown

This repo contains the product teardowns by me.

## Zepto
- Audited Zepto’s (50M+ downloads app) onboarding flow across 4 stages, flagging 4 UX gaps — including a
mandatory name field not disclosed until checkout and back-to-back promo pop-ups after orders — then pro-
posed 4 metrics to track activation and on-time delivery.
